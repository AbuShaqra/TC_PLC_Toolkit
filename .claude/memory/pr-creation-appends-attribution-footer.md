After opening a pull request through the GitHub tool, immediately update its description with the same
text and read it back: the create call appends a `---` / "_Generated by [Claude Code](…)_" footer that
the project's attribution rule (CLAUDE.md "Git attribution") forbids. An update does not re-append it.

**Why:** on 2026-11-12 the fork's CLA check logs showed the footer on every PR opened that session:
19 merged fork PRs (#114–#132) and toolkit #36 had to be edited afterwards. Writing the body without
the footer is not enough; the tool adds it on create.

**How to apply:**
- Create the PR, then `update_pull_request` with the body you wrote, then `pull_request_read` and
  confirm the body has no "Claude Code".
- The same applies in the STruC++ fork (`AbuShaqra/STruCpp`).
- Squash-merge commit messages are written by hand, so they carry no footer; check them anyway.
